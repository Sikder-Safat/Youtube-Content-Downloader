One-time setup required - cookies.txt needed for YouTube
Instructions ▾

YouTube blocks automated access. Export your browser cookies once using a free extension, place the file next to server.py, then restart the server.

  1. Install the Get cookies.txt LOCALLY extension:
    Chrome / Edge Firefox
  2. Log into youtube.com, then click the extension and hit Export.
  3. Save as cookies.txt in the project folder (same level as server.py).
  4. Restart the server: python server.py
